# 三、核心规则

本章节定义游戏规则。

## 棋盘

棋盘为(5~10)\*(5~10)大小的矩形(如6\*8棋盘也是合法的)，其中可能生成随机障碍物，但是障碍物周围不会有其他障碍物，障碍物比率约1/20。
可记A方棋子为num1，B方棋子为num2，空白地区为0，障碍物为num3来标识地图，可使用矩阵进行表示。
可视化时使用python库或其他方式暂时可视化为色块，后续开发可能换成图像资源。
两方棋子可分别使用克莱因蓝和勃艮第红的正方形表示，空白地区为白色，障碍物地区为黑色。

## 棋子

A方和B方拥有初始棋子数量相同，都是棋盘短边长+1个棋子，随机分别生成在地图上侧(A方)和下侧(B方)尽可能靠边的位置。

## 坐标系统

地图由矩形构成，地图左下角坐标为(0,0)，水平向右一格为(1,0)，水平向上一格为(0,1)，依此类推(x,y)。

# 五、回合流程

待补充：

* 玩家可执行动作：每次玩家回合开始可按照移动规则移动一颗棋子，随后该玩家回合结束。
* 回合切换规则：每次玩家回合开始后移动一颗棋子，随后回合结束并切换为另一玩家回合，
* 特殊情况处理：发生吃子等特殊情况不影响回合，直到回合结束。若该玩家所有棋子无法移动则对方玩家继续一回合。

# 六、移动规则

玩家每次可以移动自己的一颗棋子一格，移动到水平位置和垂直位置的相邻无内容格子，不能斜走(如(0,0)不能到(1,1))。
无法将自己的棋子移动到自己的棋子、敌方的棋子或障碍物上。

## 棋子类型

### 示例

棋子名称：

所有棋子均一样，不分棋子名称，可以命名为cannonchess。

移动规则：

每次可以移动自己的一颗棋子一格，移动到水平位置和垂直位置的相邻无内容格子，不能斜走(如(0,0)不能到(1,1))。
无法将自己的棋子移动到自己的棋子、敌方的棋子或障碍物上。

吃子规则：

吃子规则如下，若两个棋子在移动后连一条线，则可以吃掉其延长线一格距离的敌方棋子，不能吃掉友方棋子和障碍物。
举例，如A方棋子为1，B方棋子为2，空地为0，则可以发生如下吃子规则：
初始状态：
[[0, 1, 0],
 [2, 0, 0],
 [0, 2, 0]]
此时B方移动第二行的棋子到中间，状态变为：
[[0, 1, 0],
 [0, 2, 0],
 [0, 2, 0]]
这时B方两个棋子连为一条线，可以吃掉A方棋子：
[[0, 0, 0],
 [0, 2, 0],
 [0, 2, 0]]
注意吃子距离只有一个，如果为：
[[0, 1, 0],
 [0, 0, 0],
 [0, 2, 0],
 [0, 2, 0]]
则吃不到A方棋子。
吃子不限于竖着，水平方向也可以发生如下吃子，但是不能吃掉斜着的棋子。

特殊规则：
若一方所有棋子无法移动，则另一方继续一回合。

# 七、胜负判定

当一方的棋子数量小于2时(只剩下1颗棋子或者无棋子)，则该方失败，另一方胜利。

# 八、平局判定

若两方持续移动10回合未发生吃子，则判定平局。

# 九、非法状态

* 非法坐标：棋子不会位于障碍物或任何棋子上，不会位于地图之外。
* 非法移动：棋子不能移动到障碍物或任何棋子上，只能向上下左右移动，不能斜向移动。
* 非法棋盘状态：暂无。

# 十、程序功能需求

##  程序功能

程序开始后首先选择游戏模式，分为双人本地游玩，双人远程游玩，单人AI对战。

功能实现：

* 双人本地对战：可以支持双人轮流移动，使用同一个鼠标操作即可，可以调用pygame等库进行下棋。
* 双人远程游玩：可以两人同时运行该程序并选择双人远程，二人处于同一局域网下，使用TCPIP连接对方电脑后即可游玩。
* 单人AI对战：可以支持AI玩家对战，单人和内置胜利逻辑的AI进行对战，AI使用传统方式计算得分策略来尽量取得胜利。

附加功能：
* AI玩家：使用传统方法计算得分率和什么逻辑可以吃掉对方棋子，可以使用epsilon-greedy策略，尽可能选最有利的但小概率选其他方法。
* 悔棋功能：玩家可以选择悔棋或者投降认输或者重新开始本次对局。
* 图形界面：可使用绘图库或pygame等，允许鼠标交互控制棋子移动，使用高透明度的淡黄色提示棋子可移动位置。
