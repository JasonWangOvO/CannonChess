# CannonChess

炮棋 Python 原型，当前实现双人本地对战、单人 AI 对战和图形界面。

## 运行

无需第三方依赖，使用 Python 3.10 标准库。

```bash
python run_game.py
```

也可以安装为包后运行：

```bash
python -m cannonchess
```

## 当前功能

- 程序启动后进入模式选择。
- 双人本地对战可用，同一鼠标轮流移动。
- 单人 AI 对战可用，人类执 A 方，AI 执 B 方。
- 双人远程游玩可用，支持同一局域网内 TCP 直连。
- 每局随机生成 5-10 范围内的矩形棋盘，棋子数量为短边长 + 1。
- 障碍物按约 1/20 比例生成，上半区和下半区数量尽量均衡。
- 地图中心附近生成一个果实，颜色为 `#A94064`，显示为 `^_^`。
- A 方使用克莱因蓝方块，B 方使用勃艮第红方块。
- 障碍物为黑色边框的棕色方块，空地为白色。
- 选中棋子后以淡黄色提示可移动位置。
- 支持悔棋、投降、重新开始当前对局、新的一局。
- 支持局内“规则”按钮，展示基础移动、吃子和胜利规则。
- 支持胜负判定和 200 回合无吃子平局判定。
- 吃子只由本次移动的棋子与己方相邻棋子成线触发；移动棋子可以是这组相邻棋子的任意一端。静态成线不会因其他棋子移动而吃子。
- 吃子目标背后一格如果有棋子或障碍，则触发“两格打不穿”，不会吃掉该目标。
- 果实可以被炮吃掉；吃掉果实的一方会在己方半区靠边位置生成一颗己方棋子。

## AI 算法

第一版 AI 使用传统启发式搜索，不依赖训练数据。AI 会先按“能否吃子、是否形成更好局面”等快速指标给合法走法排序，只保留少量候选走法，再向后搜索较浅的对局变化；搜索过程中使用 alpha-beta 剪枝跳过明显不会影响最终选择的分支。

到达搜索深度上限或终局时，AI 用局面评分函数估算优劣。评分主要考虑胜负结果、双方棋子数量差、合法移动数量差、当前可吃子机会，以及接近平局时的局势压力。这个版本优先保证 GUI 响应速度，棋力会弱于完整深度搜索；同分时会随机选择一个，避免每局表现完全固定。

## 工程结构

- `src/cannonchess/core.py`：纯规则逻辑。
- `src/cannonchess/gui.py`：Tkinter 图形界面。
- `src/cannonchess/agents.py`：AI 接口和启发式搜索 Agent。
- `src/cannonchess/network.py`：局域网远程对战的 TCP 消息收发和状态序列化。
- `tests/test_core.py`：核心规则测试。
- `tests/test_agents.py`：AI 策略测试。
- `tests/test_network.py`：远程对战消息序列化测试。

## 局域网远程对战

两台电脑需要先通过外部方式处于同一局域网内。

创建方选择“创建房间”，填写监听端口，默认 `5000`。创建成功后，将本机局域网 IP 和端口告诉另一名玩家。加入方选择“加入房间”，输入创建方 IP 和端口即可连接。

远程模式中，创建方执 A 方，加入方执 B 方。主机生成初始棋局并发送给加入方，之后双方同步走法、悔棋、重新开始、新的一局和投降状态。该模式面向朋友间游玩，不做反作弊校验。

“重新开始”会回到当前地图的初始状态；“新的一局”会重新生成随机地图。两名玩家都可以发起悔棋、重新开始和新的一局。

## 修改规则弹窗

局内“规则”按钮显示的文本定义在 `src/cannonchess/gui.py` 顶部的 `RULES_HELP_TEXT` 常量中。后续如果要调整玩家提示内容，直接修改这个常量即可。

果实的棋盘数值、生成和吃果实奖励逻辑在 `src/cannonchess/core.py` 中；果实颜色和 `^_^` 显示在 `src/cannonchess/gui.py` 中。
